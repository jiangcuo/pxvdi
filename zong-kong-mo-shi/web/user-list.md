# 用户列表

入口：**主页 → 用户 → 用户管理 → 用户列表**。

页面展示用户名称、昵称、所属域、部门和启用状态。可按账号、部门、状态和域筛选，再点击**搜索**刷新结果。

## 添加用户

1. 点击**添加用户**。
2. 填写用户名称和密码，选择用户类型；AD 用户还需选择所属域。
3. 按需要填写昵称、部门、手机号、邮箱和备注。
4. 检查信息后点击**确认**，返回列表核对所属域与状态。

| 字段 | 填写要求 |
| --- | --- |
| 用户名称 | 平台/AD 用户为 2～20 位，以字母开头、字母或数字结尾，中间可用字母、数字、下划线和连字符 |
| MAC 用户名称 | 终端 MAC 地址，如 `AA:BB:CC:DD:EE:FF`；也支持连字符分隔 |
| 用户密码 | 当前表单至少 6 位；AD 密码还需满足域自身的密码策略 |
| 用户部门 | 可选；用于组织账号及部门授权 |
| 所属域 | AD 类型按所选域创建账号；应先完成域连接配置 |

## 编辑、停用与重置密码

使用行内**编辑**更新用户资料。AD 和 MAC 用户的名称不能在编辑表单中更改。编辑资料与重置密码分别操作。

状态开关用于启用或停用账号。**重置密码**用于更新账号密码；AD 用户的状态和密码变更会同步到域。平台内置 `admin` 账号受保护，不能删除或停用。

## 导入用户

1. 点击**导入用户**，选择平台或 AD 类型；AD 导入需选择所属域。
2. 点击**下载模板**，使用该模板填写账号数据。
3. 上传 `.xlsx` 文件，文件必须小于 10 MB。
4. 查看导入结果；如有跳过的记录，按用户名和失败原因修正后再处理。

上传文件后即开始导入。当前导入入口不支持 MAC 用户；请使用添加用户或客户端注册流程。

## 同步 AD 用户

点击**同步用户**，按界面选择域并执行同步。平台会根据 AD 中的用户更新本地账号记录，包括新增、状态变更和已移除对象。同步前确认域连接正常；同步后的桌面授权仍需在桌面池中配置。

## 删除用户

可逐行删除、勾选后**删除选中**，也可通过**批量删除**下载用户清单，在删除标记列填写 `1`，上传并核对待删除对象后确认。

::: warning 删除影响
删除 AD 用户会删除实际域账号。批量操作前按域和用户类型缩小范围，并核对待删除名单。删除账号会影响其桌面访问，平台管理员 `admin` 不参与删除。
:::
