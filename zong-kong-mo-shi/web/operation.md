# 运维模块

入口：**主页 → 运维**。

运维模块集中展示平台状态、日志和配置。排查问题时先确定发生时间、用户及目标桌面，再进入相应页面查询。

| 页面 | 用途 |
| --- | --- |
| [系统摘要](./system-overview.md) | 查看平台运行摘要 |
| [用户日志](./user-log.md) | 查询用户访问记录 |
| [集群日志](./cluster-log.md) | 查询集群相关事件 |
| [平台配置](./platform-config.md) | 维护平台级参数 |
| [客户端管理](./client-manage.md) | 管理客户端相关配置与维护任务 |

## 排查顺序

登录与访问问题先核对[用户状态](./user-list.md)、[域连接](./domain.md)及桌面授权；连接问题再检查桌面服务、网络和协议。共享池的路由结果与授权变更，可在[共享池记录](./shared-pool.md#排查连接问题)中进一步定位。
