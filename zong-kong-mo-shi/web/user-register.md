# 用户注册审核

入口：**主页 → 用户 → 用户管理 → 用户注册**。

客户端提交的注册申请显示在此页面。管理员按账号搜索，并在**待审核、已通过、已拒绝**三个状态间切换。

## 审核流程

1. 在**待审核**中核对用户名称、姓名、域名和注册时间。
2. 对单条申请点击**审核**；或勾选多条申请后点击**批量审核**。
3. 选择通过或拒绝，并确认处理。
4. 通过后，在[用户列表](./user-list.md)检查账号状态，再配置桌面分配或共享池授权。

平台和 MAC 用户通过审核后默认启用。AD 注册通过时会在域中创建账号，但平台记录默认停用；管理员还需检查并启用该账号。审核通过不会自动分配桌面。

MAC 注册常用于瘦客户端和机房终端，后续步骤参阅[终端管理](./terminalmgr.md)。
