# 机房模式

入口：**主页 → 机房模式**。

机房模式以机房和终端组织教学桌面，适用于教室或集中终端场景。教学桌面池按机房、终端和桌面关联交付，管理员可根据课程切换不同桌面环境。

| 页面 | 用途 |
| --- | --- |
| [机房管理](./serverroom.md) | 建立机房并维护机房信息 |
| [终端管理](./terminalmgr.md) | 接入终端，完成注册、审核和终端维护 |
| [教学桌面池](./sdupool.md) | 配置教学桌面与终端的关联 |

## 配置顺序

1. 建立机房，确定终端归属。
2. 部署终端服务并注册 MAC 用户，在**用户 → 用户管理 → 用户注册**审核申请。
3. 将终端加入机房，准备教学桌面资源。
4. 创建教学桌面池并关联终端与桌面，验证终端登录后的资源可见性。

可按课程准备 Windows、Linux 等不同桌面池，再启用适合当前课程的环境。共享会话桌面池面向池级授权与会话路由，相关说明见[共享会话桌面池](./shared-pool.md)。
