# 平台配置

平台配置用于管理 PXVDI Server 自身配置和升级操作，是平台级高风险变更页面。

这页里的动作，很多都会直接影响整个平台的可用性，因此建议只由明确授权的管理员来执行。

## 上传升级包并更新

### 操作步骤

1. 打开`运维模块 -> 平台配置`。
2. 点击`上传文件`。
3. 选择新的平台升级包。
4. 等待上传完成。
5. 点击`确认升级`。
6. 等待升级任务完成。
7. 如有要求，再执行平台重启。
8. 升级后重新登录，并到`系统摘要`确认版本。

## 重启平台

### 操作步骤

1. 在平台配置页找到`重启平台`。
2. 点击执行。
3. 再次确认。
4. 等待平台恢复。
5. 恢复后重新登录检查。


## 重置 VNC

本操作可以重置平台绑定的VNC用户密码。

### 操作步骤

1. 在平台配置中找到`重置 VNC`。
2. 点击执行。
3. 等待成功提示。
4. 再回到桌面详情测试控制台或远程连接是否恢复。

## 重置连接 API Key

本操作可以重置平台绑定的PXVIRT 服务器的apikey。如果原来的apikey失效，可以使用此功能。

### 操作步骤

1. 在平台配置中找到`重置连接 API Key`。
2. 点击执行。
3. 在弹窗中输入 PXVIRT 管理密码。
4. 点击确认。
5. 等待系统返回重置成功。
6. 重置后回到集群相关页面确认连接正常。

### 这里要求输入的是什么密码

通常是当前 PXVIRT 管理端 `root@pam` 对应的密码，用于重新建立平台与 PXVIRT 的管理连接。


## 修改 PXVIRT 服务器地址

本操作可以修改平台绑定的 PXVIRT 服务器地址。用于更换pxvirt集群

### 操作步骤

1. 在平台配置中找到`修改 PXVIRT 服务器地址`。
2. 点击执行。
3. 输入新的 PXVIRT 地址。
4. 点击确认保存。
5. 保存后回到首页、集群模块和虚拟机模块检查数据是否正常加载。
