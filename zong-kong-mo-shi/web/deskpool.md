# 桌面池模块

入口：**主页 → 桌面池**。

桌面池把桌面资源、用户授权和连接策略组织为可交付的桌面服务。账号与域在独立的[用户模块](./user.md)中准备，再回到桌面池完成授权和策略配置。

## 功能导航

| 页面 | 用途 |

| [桌面池管理](./pool.md) | 创建和维护普通、快照及共享会话桌面池 |
| [共享会话桌面池](./shared-pool.md) | 配置成员桌面、池级授权、容量和路由 |

| [桌面状态](./desktop-status.md) | 查看在线桌面及执行会话管理操作 |

## 两种交付关系

| 交付方式 | 桌面关联 | 用户如何获得资源 |
| --- | --- | --- |
| 普通 / 快照桌面池 | 桌面加入池，继承池策略 | 将用户分配到具体桌面 |
| 共享会话桌面池 | 多台桌面构成共享服务 | 授权用户、部门或 AD 安全组，由平台路由连接 |

一个桌面只能关联一个桌面池。用户可以获得多个已授权桌面或池入口。建立用户、创建虚拟机或创建空池都不会单独完成交付，还需建立资源关联和访问授权。

## 配置顺序

准备桌面和用户 → 创建桌面池 → 配置策略 → 添加桌面 → 分配或授权用户 → 使用客户端验证。

USB 设备库是全局规则库；具体允许或禁止哪些 USB 设备，在每个池的[USB 策略](./usb-policy.md)中选择。共享会话桌面池强制关闭 USB 重定向。
