# 桌面池管理

入口：**主页 → 桌面池 → 桌面池管理**。

列表用于搜索、创建、编辑、启用或禁用桌面池，以及进入**查看桌面**维护成员与授权。展开行可查看策略摘要。

## 选择桌面池类型

| 类型 | 适用场景 | 交付方式与限制 |
| --- | --- | --- |
| 普通桌面池 | 固定办公桌面 | 添加现有桌面，并将用户分配到具体桌面 |
| 快照桌面池 | 基于 PXVDI 模板批量交付 | 依赖 PXVIRT；PVE 和独立模式不提供新建入口 |
| 共享会话桌面池 | 多用户访问一组会话桌面 | 池级授权、容量路由；详见[共享会话桌面池](./shared-pool.md) |

桌面池类型保存后不能更改。教学场景请从[机房模式](./terminal.md)创建教学桌面池。

## 创建与编辑

点击**添加桌面池**，按向导使用**下一步、上一步**配置。普通池依次包含：基本信息 → 网关策略 → 资源策略 → USB 策略 → 连接策略 → 账号策略。

向导最后点击**确认提交**才保存池配置。关闭向导会放弃尚未提交的池修改；但 USB 步骤中的“新增设备”是独立保存到全局设备库的操作，参阅[USB 设备](./usb-device.md)。

### 基本信息

填写名称、选择类型，并按需要添加备注。编辑已有池时类型固定。

### 网关策略

网络隔离或外部访问场景可以启用网关，并选择已配置的网关。桌面网关和 Moonlight 网关分别配置，需与实际连接协议、网关服务和网络路径一致。

网关的添加及参数说明参阅[网关管理](./gateway.md)。

### 资源策略

按业务需要配置声音、麦克风、驱动器、剪切板、打印机、目录、串口等重定向，以及多监视器和调试功能。实际可用功能取决于协议、客户端系统及桌面端服务。

剪切板开启后，数据与文件可分别选择**双向、桌面→终端、终端→桌面、禁用**。方向以桌面操作系统和用户终端为参照。

**允许还原**向用户开放桌面快照还原能力，可能影响桌面数据，应结合业务恢复要求配置。共享池不提供此选项。

### USB 策略

普通池可设置 USB 总开关、黑白名单、设备种类和指定设备。共享池跳过此步骤且强制关闭 USB 重定向。完整规则与迁移说明参阅[USB 策略](./usb-policy.md)。

### 连接策略

普通池支持 `pxvdi`、`spice`、`freerdp2`、`freerdp3`、`pcoip`、`blast`、`moonlight` 和 `all`。共享池支持 `pxvdi`、`freerdp2`、`freerdp3` 和 `all`。

`all` 允许客户端使用池支持的连接方式，具体选择受客户端偏好及能力影响。指定单一协议时，客户端按池策略连接。桌面端必须部署对应服务，选择协议本身不会安装服务。

| 参数 | 配置说明 |
| --- | --- |
| SPICE 代理 | 普通池选择 `spice` 或 `all` 时必填；PXVIRT/PVE 常见地址为节点的 `地址:3128`，需保证客户端可达 |
| PXVDI 模式的 SPICE 代理 | 当前表单允许留空；新版 PXVDI USB 重定向不以此项为前提 |
| RDP 端口 | 默认 `3389`，应与桌面端实际监听端口一致 |
| 编解码、色深、网络速率 | 按网络条件与客户端协议能力选择，先验证默认值再调整 |
| 启用中继 | 按部署填写 TURN 服务端点及认证信息，确保服务可用 |

### 账号策略

账号策略决定连接桌面操作系统时使用的身份，不适用于 SPICE 登录。

| 策略 | 行为 |
| --- | --- |
| 均不使用 | 不在池中固定桌面凭据，通过客户端的登录或交互流程提供 |
| 只使用用户名 | 使用池配置的用户名，不在池中固定密码；按实际连接流程提供密码 |
| 均使用 | 使用池配置的用户名和密码 |
| AD 账号密码 | 使用用户登录时的域账号凭据，桌面需具备相应域登录环境 |

共享池固定使用当前 AD 账号策略，跳过此配置步骤。普通池采用平台凭据时，需确保桌面系统中存在相匹配的账号。不要仅为绕过登录失败而关闭 NLA，应先检查身份、域、协议和认证支持。

## 分配桌面

创建普通池后，点击**查看桌面**，使用**添加桌面**将现有资源加入池，再为具体桌面**分配用户**。快照池的模板准备参阅[PXVDI 模板管理](./vm-pxvdi-template.md)。

完成后用目标用户登录客户端，确认桌面可见且能连接。若不可见，检查用户状态、池是否启用、资源关联及用户分配。共享池无需逐桌面分配，使用[池级授权](./shared-pool.md)。

## 关机还原

PXVIRT 的关机还原可将桌面恢复至开机前的状态，适用于需要清理用户改动的场景。启用前明确数据保留要求，并确认平台与虚拟机配置支持该功能。

具体配置参阅 [PXVIRT 快照文档](https://docs.pxvirt.lierfang.com/zh/cli/qm.html#snapshot)。
