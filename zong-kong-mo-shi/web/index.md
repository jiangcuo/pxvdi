# 管理系统介绍

本目录介绍 `PXVDI For PXVIRT 总控模式` 的 Web 管理系统。

这套文档不是只告诉你“这个菜单叫什么”，而是尽量回答下面这些实际问题：

- 这个页面是做什么的
- 我应该先点哪里，后点哪里
- 这个字段填什么才算合理
- 多个选项之间有什么区别
- 一个完整场景应该按什么顺序做

## 这套文档适合谁

更适合下面这些角色：

- 平台实施人员
- 日常运维人员
- 机房管理员
- 桌面管理员
- 账号、网关、域配置管理员
- 负责模板、备份、客户端维护的管理员

## 管理系统的 4 个主入口怎么理解

### 虚拟机

这里主要处理“机器本身”。

适合做：

- 创建虚拟机
- 管理普通桌面
- 管理 PVE 模板和 PXVDI 模板
- 备份、还原、克隆、迁移
- 修改单台桌面计算、存储、网络配置

### 桌面池

这里主要处理“怎么把桌面交付给用户”。

适合做：

- 管理用户和部门
- 接入域
- 配置网关
- 建立桌面池
- 看桌面在线状态
- 给在线桌面发消息、发文件、管会话

### 集群

这里主要处理“PXVIRT 底层资源”。

适合做：

- 查看集群整体资源
- 查看节点状态
- 新增或维护节点
- 查看存储池、ISO、备份和镜像文件

### 运维

这里主要处理“平台自身和终端设备”。

适合做：

- 看系统摘要和授权
- 查看用户日志、集群日志
- 升级平台、修改平台配置
- 管理客户端设备和远程脚本

## 第一次实施建议按什么顺序读

### 从零部署平台

建议阅读顺序：

1. `安装`
2. `登录页面`
3. `主页`
4. `集群模块`
5. `虚拟机管理`
6. `桌面池模块`
7. `运维模块`

### 日常运维排障

建议按问题分类查：

- 登录不上：看`登录页面`
- 桌面出问题：看`桌面管理`和`桌面详情`
- 用户拿不到桌面：看`用户管理`、`桌面池管理`、`网关管理`、`域管理`
- 节点和存储异常：看`集群模块`
- 平台升级或客户端异常：看`运维模块`

## 一套推荐的上线实施顺序

如果你要把平台从零搭好并开放给用户，推荐按下面顺序操作：

1. 安装 PXVDI Server 并完成初始化。
2. 登录系统，先修改管理员密码。
3. 到`集群模块`确认节点和存储正常。
4. 在`虚拟机管理`准备模板或普通桌面。
5. 在`桌面池模块`准备域、用户、部门、网关。
6. 在`桌面池管理`中建立桌面池策略。
7. 在`桌面状态`中确认在线桌面和交付效果。
8. 在`运维模块`中确认授权、日志和客户端状态。

## 常见工作流怎么串起来

### 场景 1：做一批固定办公桌面

1. 在`虚拟机管理`准备一批普通虚拟机。
2. 在`用户管理`新增或导入办公用户。
3. 在`网关管理`准备内外网接入方式。
4. 在`桌面池管理`建立普通桌面池。
5. 分配用户并做连接测试。
6. 在`桌面状态`观察用户上线情况。

### 场景 2：做一批快照教学桌面

1. 先在`PXVDI 模版管理`准备好模板。
2. 在`用户管理`导入或同步教学用户。
3. 在`桌面池管理`建立快照桌面池。
4. 关闭不必要的 USB、磁盘、剪切板能力。
5. 开启回滚等统一环境策略。
6. 在`桌面状态`中做统一通知和会话管理。

### 场景 3：桌面突然大面积异常

1. 先到`运维 -> 系统摘要`看平台状态。
2. 再看`集群 -> 集群概览`看底层资源。
3. 看`运维 -> 集群日志`有没有大面积任务失败。
4. 再到`桌面状态`看在线桌面是否集中掉线。
5. 最后回到具体节点、虚拟机或客户端页面排查。

- 这个页面解决什么问题

- 哪些选项的区别最大
- 做完后到哪里确认结果
