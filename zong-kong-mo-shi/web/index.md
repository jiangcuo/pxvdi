# 管理系统使用指南

PXVDI 管理系统用于管理桌面资源、用户身份和交付策略。管理员在浏览器中完成配置，用户通过 PXVDI 客户端获取已授权的桌面。

本指南按新版主页的六个入口组织。**用户**已成为独立模块；**桌面池**集中管理交付策略，并新增 **USB 设备**库。界面截图取自当前运行的管理系统，具体功能是否可用取决于产品版本、授权和部署模式。

## 首次交付桌面的顺序

1. 完成[安装](./install.md)和[登录](./login.md)，检查平台配置及资源接入。
2. 准备[虚拟机](./vmmgr.md)或[外部桌面](./external-desktop.md)，配置连接服务，确认桌面与客户端之间的网络可达。
3. 在[用户模块](./user.md)准备账号；使用 AD 时先完成[域接入](./domain.md)，按需要建立[部门](./department.md)或 AD 安全组。
4. 创建[桌面池](./pool.md)，配置网关、资源、USB、连接和账号策略。
5. 将桌面加入池中。普通池按桌面分配用户；[共享会话桌面池](./shared-pool.md)在池级别配置授权和容量。
6. 使用一个已授权账号登录客户端，验证桌面可见性、连接和资源重定向。

## 按问题查找说明

| 遇到的问题 | 优先检查 |
| --- | --- |
| 登录失败或账号不可用 | [用户状态](./user-list.md)、[注册审核](./user-register.md)、[域连接](./domain.md) |
| 登录成功但看不到桌面 | 桌面池是否启用、桌面是否加入池、[用户分配](./pool.md#分配桌面)或[共享池授权](./shared-pool.md#配置访问授权) |
| 看得到桌面但无法连接 | [连接策略](./pool.md#连接策略)、桌面服务、网络、网关和账号策略 |
| USB 设备无法重定向 | [USB 策略](./usb-policy.md)、客户端与桌面 Agent 版本、设备驱动 |
| 共享池没有可用桌面 | [成员容量与路由记录](./shared-pool.md#排查连接问题) |

客户端的登录、连接及本地设置请参阅[桌面客户端使用说明](../../client/Usage.md)。本指南中的“用户”指平台账号；“桌面系统账号”指 Windows、Linux 等桌面操作系统中的账号，两者需要通过账号策略衔接。
