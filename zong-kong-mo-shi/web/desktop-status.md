# 桌面状态


桌面状态用于集中查看平台内外桌面的在线情况、会话信息，并执行实时控制动作。

如果说`桌面池管理`是在配策略，那么`桌面状态`更像是在看“当前已经交付出去的桌面现在怎么样”。

`当外部桌面和内部桌面都被加入到桌面池里面`，才会在桌面状态中显示，

对于在线桌面，可以进行操作，比如文件部署，

![alt text](../../img/deskstatus1.png)

包括这些功能

- 发送消息弹窗
- 文件部署弹窗
- 部署进度弹窗
- 文件管理器弹窗
- 终端弹窗

## 发送消息

1. 勾选目标在线桌面，或决定按桌面池发送，或发送给所有在线桌面。
2. 点击`发送消息`。
3. 选择目标类型。
4. 如按桌面池发送，选择目标桌面池。
5. 填写标题、消息类型、宽度和内容。
6. 点击发送。
7. 检查是否有离线桌面未送达。

发送消息字段说明

| 字段 | 含义 | 推荐值 / 示例 | 注意事项 |
| --- | --- | --- | --- |
| 目标类型 | 发送给谁 | `选中桌面`、`按桌面池`、`所有在线` | 离线桌面无法发送 |
| 桌面池 | 当目标类型为按池时必填 | `高一考试池` | 只会影响该池内在线桌面 |
| 标题 | 消息标题 | `10分钟后维护` | 建议简洁明确 |
| 消息类型 | 弹窗风格 | `info`、`success`、`warning`、`error` | 影响显示颜色和提醒感知 |
| 弹窗宽度 | 客户端弹窗宽度 | 默认 `400px` | 前端通常允许 `300-800px` |
| 内容 | 消息正文 | 支持 Markdown 文本 | 建议写清时间、动作要求、影响范围 |

消息类型怎么选

- `info`：普通通知，适合一般提醒。
- `success`：成功类提示，适合发布完成或恢复通知。
- `warning`：重要提醒，适合维护、下线、保存数据通知。
- `error`：强提示，适合故障、紧急下线通知。

## 文件部署（preview功能）

1. 勾选目标在线桌面，或选择按池 / 全部在线。
2. 点击`文件部署`。
3. 选择目标类型。
4. 选择上传新文件，或从已上传文件中选择。
5. 选择目标路径。
6. 决定传输后是仅保留、立即执行，还是其他后处理动作。
7. 如选择执行，再填写执行参数、超时时间和是否执行后删除。
8. 提交开始部署。
9. 打开部署进度窗口查看结果。

文件部署字段说明

| 字段 | 含义 | 推荐值 / 示例 | 注意事项 |
| --- | --- | --- | --- |
| 目标类型 | 部署到谁 | `选中桌面`、`按桌面池`、`所有在线` | 占用带宽很大！ |
| 桌面池 | 按池部署时必填 | `办公池-A` | 适合分批次下发 |
| 部署文件 | 这次要下发的文件 | 新上传安装包 / 已上传文件 | 只能在在线桌面上执行 |
| 目标路径 | 文件放到桌面里的哪个路径 | 预设目录或自定义目录 | 自定义路径要确保客户端有权限 |
| 传输后动作 | 仅传输 / 立即执行 | 安装包通常选执行 | 高风险程序建议先小范围验证 |
| 执行参数 | 程序启动参数 | `/silent`、`/qn` | 按安装包规范填写 |
| 执行超时 | 等待执行结果的时间 | `300` 秒 | 前端常见范围 `30-3600` 秒 |
| 执行后删除文件 | 是否自动删掉文件 | 临时安装包常开启 | 便于减少残留文件 |

## 文件管理器（preview功能）

1. 在目标桌面的操作菜单中选择`文件管理器`。
2. 进入后查看当前目录。
3. 可使用返回、主页、刷新等工具按钮。
4. 如需上传文件，选择上传。
5. 如需新建目录，点击新建文件夹。
6. 对具体文件执行下载或删除。
