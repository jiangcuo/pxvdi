# 集群模块

入口：**主页 → 集群**。

集群模块用于查看和维护接入的 PXVIRT/PVE 资源。部署模式会影响可用功能；独立模式的外部桌面不依赖此模块进行虚拟化资源管理。

| 页面 | 用途 |
| --- | --- |
| [集群概览](./cluster-overview.md) | 查看集群整体资源和运行状态 |
| [节点管理](./node.md) | 查看节点状态及节点相关资源 |
| [存储管理](./storage.md) | 检查存储状态、容量和可用性 |

## 资源检查

桌面创建、克隆或备份失败时，先检查节点是否在线、存储是否可用及剩余容量，再结合[集群日志](./cluster-log.md)定位具体原因。桌面授权和连接策略在[桌面池模块](./deskpool.md)中配置。
