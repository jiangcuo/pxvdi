# 主页

登录后进入管理系统主页。左侧六个入口分别打开对应的管理窗口，窗口内的左侧菜单用于切换功能页面。

## 六个模块

| 入口 | 常用操作 |
| --- | --- |
| [虚拟机](./vm.md) | 查看桌面、管理虚拟机、模板和备份 |
| [桌面池](./deskpool.md) | 创建桌面池、配置策略、维护 USB 设备库、查看桌面状态 |
| [用户](./user.md) | 添加和导入账号、审核注册、调整部门、维护域和目录对象 |
| [机房模式](./terminal.md) | 管理机房、终端和教学桌面池 |
| [集群](./cluster.md) | 查看集群状态、节点与存储 |
| [运维](./operation.md) | 查看系统摘要与日志、配置平台、管理客户端 |

## 使用管理窗口

打开模块后，先从窗口左侧选择菜单，再使用页面上方的搜索、筛选或操作按钮。窗口右上角提供放大和关闭控件；关闭窗口后可从主页重新打开。

用户管理中的**用户列表、用户注册、部门管理**通过顶部标签切换。域管理和域目录位于同一模块的左侧菜单。USB 设备管理则位于**桌面池 → USB 设备**。
