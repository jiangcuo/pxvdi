# 主页

PXVDI 总控模式管理平台的主页采用桌面式布局，主要作用是把四个主模块以“桌面图标”的方式呈现出来。

主页不是干具体业务的地方，而是“进入各业务模块的总入口”。


### 左侧桌面入口区

当前前端中有 4 个一级入口：

- `虚拟机`
- `桌面池`
- `集群`
- `运维`

点击后，系统通常会以窗口形式打开对应模块，而不是整页跳转。

### 顶部功能区

- 平台 Logo
- 语言切换
- 当前管理员菜单

### 虚拟机

适合处理：

- 单台虚拟机配置
- 模板
- 备份
- 克隆、迁移、快照

### 桌面池

适合处理：

- 用户
- 部门
- 域
- 网关
- 桌面池
- 在线桌面状态

### 集群

适合处理：

- 节点
- 存储
- 集群资源趋势

### 运维

适合处理：

- 系统摘要
- 日志
- 平台升级
- 客户端管理

## 顶部管理员菜单

### 修改密码

1. 点击右上角管理员账号。
2. 选择`修改密码`。
3. 输入新密码并确认。
4. 保存后重新登录验证。

### 退出系统

1. 点击右上角管理员账号。
2. 选择`退出系统`。
3. 系统会返回登录页。
