# 桌面管理

桌面管理用于查看平台中的普通虚拟机，并执行最常用的日常运维动作。


## 页面区域

- 顶部搜索区
- 顶部操作按钮区
- 已选数量提示区
- 虚拟机列表区
- 行内操作区

## 搜索区支持

支持以下功能筛选

- 虚拟机 ID
- 虚拟机名称
- 所属节点
- 所属桌面池
- 所属用户

## 搜索虚拟机的完整步骤

1. 在顶部输入虚拟机 ID 或名称。
2. 如有需要，再选择所属节点、桌面池或用户。
3. 点击`搜索`。
4. 列表刷新后查看结果。
5. 如要恢复全量列表，清空条件后再次搜索。


## 顶部操作按钮区


- `创建虚拟机`
- `刷新列表`
- `批量分配用户`
- `批量操作`

### 创建虚拟机

1. 点击`创建虚拟机`。
2. 在创建向导中依次填写节点、名称、CPU、内存、磁盘、网络等参数。
3. 确认后提交。
4. 创建完成后回到列表刷新。
5. 再视情况为该桌面分配用户或桌面池。


### 批量分配用户

1. 在列表中勾选一台或多台虚拟机。
2. 点击`批量分配用户`。
3. 在弹窗中选择目标用户。
4. 确认保存。
5. 返回列表检查是否已绑定成功。


### 批量操作

前端常见批量操作包括：

- `批量停止`
- `批量开机`
- `批量快照`
- `批量还原快照`
- `批量销毁`

### 示例：批量开机

1. 勾选多台目标虚拟机。
2. 点击`批量操作`。
3. 选择`批量开机`。
4. 等待任务完成。
5. 刷新列表确认状态是否变为运行中。

### 示例：批量快照

1. 勾选多台虚拟机。
2. 点击`批量操作`。
3. 选择`批量快照`。
4. 输入统一快照名称。
5. 提交后等待任务执行。
6. 如个别虚拟机不支持，会出现部分成功、部分失败。


## 列表详情


| 字段 | 含义 | 说明 |
| --- | --- | --- |
| 虚拟机编号和名称 | 识别桌面的主信息 | 例如 `200(win11-office-01)` |
| 当前状态 | 运行中、关机、暂停等 | 判断是否适合后续操作 |
| 架构 | 虚拟机架构信息 | 多架构环境下有用 |
| CPU | CPU 核心数和使用情况 | 适合快速看负载 |
| 内存 | 内存配置和使用情况 | 适合判断是否需要扩容 |
| 所属节点 | 当前落在哪台宿主机 | 迁移和排障时重要 |
| 所属桌面池 | 当前是否已归属桌面池 | 交付链路里很重要 |
| 所属用户 | 当前是否已绑定用户 | 便于追踪桌面归属 |


## 单台虚拟机的行内操作

### 电源操作

每台虚拟机通常支持：

- 开机
- 关机
- 强制关机
- 重启
- 强制重启
- 恢复

#### 正常关机和强制关机

- 系统仍能响应时，优先`关机`。
- 系统卡死、无法正常关闭时，才考虑`强制关机`。

### 控制台连接

1. 在目标虚拟机所在行找到`控制台`。
2. 选择 VNC。
3. 系统会打开该虚拟机的远程控制台。

### 分配桌面池

1. 在目标虚拟机行点击`分配`。
2. 选择`分配桌面池`。
3. 在下拉框中选择目标桌面池。
4. 保存后返回列表检查结果。

### 分配用户

1. 在目标虚拟机行点击`分配`。
2. 选择`分配用户`。
3. 选择目标用户。
4. 确认保存。
5. 再次检查列表中的用户显示。

### 打开详情页

1. 点击目标虚拟机所在行的`详情`。
2. 系统会打开虚拟机详情窗口。
3. 在详情页继续处理计算、存储、网络、快照、备份等配置。

## `更多`菜单

当前包括：

- 迁移
- 备份
- 克隆
- 转模板
- 转 PXVDI 模板
- 销毁

### 迁移

1. 在目标虚拟机行打开`更多`。
2. 选择`迁移`。
3. 在弹窗中选择目标节点。
4. 确认提交。
5. 等待迁移任务完成。
6. 刷新列表确认所属节点已变化。

### 备份

1. 在`更多`中选择`备份`。
2. 选择备份格式、备份存储、备份模式。
3. 填写备注。
4. 提交后等待任务完成。
5. 完成后到`备份管理`中查看结果。

### 克隆

1. 在`更多`中选择`克隆`。
2. 选择目标节点、克隆方式、数量、起始编号等参数。
3. 提交执行。
4. 回到列表查看新生成的虚拟机。

### 转模板 / 转 PXVDI 模板

1. 先确认虚拟机已关机。
2. 在`更多`中选择对应转换动作。
3. 提交执行。
4. 完成后到对应模板页面查看结果。

> 模板转换要求虚拟机处于关机状态。
