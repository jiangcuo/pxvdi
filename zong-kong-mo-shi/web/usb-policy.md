# 桌面池 USB 策略

入口：**主页 → 桌面池 → 桌面池管理 → 添加/编辑桌面池 → USB 策略**。

USB 策略控制终端设备能否重定向到桌面。普通池默认关闭 USB 重定向；共享会话桌面池强制关闭并跳过此步骤。

## 配置顺序

1. 开启**启用 USB 重定向**。
2. 选择**黑名单**或**白名单**。
3. 按需要选择设备种类，以及[USB 设备库](./usb-device.md)中的指定设备。
4. 完成后续向导并点击**确认提交**。
5. 使用当前版本客户端和桌面 Agent 发起新连接，验证允许与禁止设备。

## 黑名单与白名单

| 模式 | 选中的类别/设备 | 未匹配的设备 | 空规则 |
| --- | --- | --- | --- |
| 黑名单 | 禁止重定向 | 允许重定向 | 不额外限制设备，仍受支持能力及 Hub 限制 |
| 白名单 | 允许重定向 | 禁止重定向 | 禁止全部设备 |

类别开关的“是”表示**加入当前名单**。例如黑名单中的“存储设备 = 是”表示禁止存储设备，而白名单中的相同设置表示允许该类设备。

可以按存储、打印机、智能卡、摄像头、音频、扫描仪/相机、通信/串口、无线/蓝牙、人机输入、厂商自定义等类别设置规则。

## 匹配规则

指定设备按 VID/PID 或仅 VID 匹配，优先于类别判断。在白名单中，明确允许的设备可以覆盖类别限制；在黑名单中，匹配到指定禁止设备就会被拒绝。

USB Hub 始终禁止重定向。复合设备在白名单模式下，所有接口都需要属于允许类别；明确匹配到指定设备允许规则时可按设备规则放行。因此，键盘与存储合一的设备不能仅凭其中一个允许接口自动放行。

UKey 不一定属于“智能卡”，也可能属于人机输入或厂商自定义。建议按实际 VID/PID 精确配置；仅 VID 会覆盖该厂商所有型号。

## 常用配置示例

| 目标 | 配置方式 |
| --- | --- |
| 禁止普通 U 盘，其余支持的设备可用 | 黑名单，选中存储设备 |
| 只允许指定型号的 UKey | 白名单，仅选择设备库中的该 VID/PID 规则 |
| 只允许打印机类设备 | 白名单，选中打印机，并验证复合打印机的接口类别 |
| 暂停该池的 USB 功能 | 关闭 USB 总开关 |

放行规则不保证设备一定可用。还需确认客户端支持重定向、终端有设备访问权限、桌面 Agent 可用，以及桌面内安装了适配驱动。打印机重定向等协议资源功能与 USB 设备重定向也应分别验证。

## 旧规则迁移

编辑含旧版 `blackusb` 规则的池时，界面会显示迁移提示，并预填可识别的类别及 VID/PID。未修改 USB 策略时保留旧规则；修改并保存后迁移到新版结构化策略。

迁移前检查提示中的未识别关键词，确认新规则能够覆盖原限制；旧 VID/PID 项按提示加入设备库。未识别的旧关键词不会自动保留为新版规则。

旧客户端无法完整执行白名单、仅 VID 和复合设备规则。使用这些功能前，统一更新客户端与桌面 Agent，并在迁移后分别测试一个允许设备和一个禁止设备。
