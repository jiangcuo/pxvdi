# 部门管理

入口：**主页 → 用户 → 用户管理 → 部门管理**。

部门用于按组织结构管理平台用户，也可作为共享会话桌面池的授权对象。左侧显示部门树，右侧显示当前部门的用户和层级路径。

## 建立部门结构

点击**添加部门**创建部门。已有部门可通过树节点的操作新建下级、编辑或删除。建议先建立部门层级，再分配成员，便于后续按组织授权。

选择实际部门后，可通过**包含下级部门**查看整个分支的成员；关闭该选项则只查看当前部门。使用用户名或昵称搜索可快速定位用户。

## 添加与调整成员

| 操作 | 结果 |
| --- | --- |
| 选中部门后添加成员 | 将选中用户归入该部门 |
| 行内调整部门 / 批量调整部门 | 将用户移动到目标部门 |
| 移出 / 移出部门 | 清空部门归属，保留用户账号 |

一个用户只有一个平台部门。从其他部门添加成员时，会改变其原部门归属。调整前应检查该用户是否依赖原部门获得共享池权限。

::: warning 删除部门
删除部门会同时删除其下级部门，并清空相关成员的部门归属，用户账号仍保留。通过该部门分支获得的桌面池授权也可能因此失效。
:::

## 按部门授权桌面池

在[共享池](./shared-pool.md#配置访问授权)中添加部门授权，会覆盖该部门及全部下级部门的成员。此授权范围与部门页面“包含下级部门”的显示开关无关。

AD 组织单位在[域目录](./ad-directory.md)中维护，不会自动形成平台部门。
