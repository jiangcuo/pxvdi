# 虚拟机管理

入口：**主页 → 虚拟机**。

此模块管理桌面资源、模板与备份。准备好资源后，到[桌面池模块](./deskpool.md)配置交付策略和用户授权。

| 页面 | 用途 |
| --- | --- |
| [桌面管理](./vmmgr.md) | 查询资源，执行开关机等日常操作，进入单台桌面详情 |
| [虚拟机详情](./vmdetail.md) | 查看和修改配置，执行迁移、备份、快照和克隆 |
| [PVE 模板管理](./vm-pve-template.md) | 管理 PVE 原生模板，克隆普通桌面 |
| [PXVDI 模板管理](./vm-pxvdi-template.md) | 为快照桌面池准备统一镜像 |
| [备份管理](./vm-backup.md) | 查询、还原和删除历史备份 |

## 交付前检查

确认桌面操作系统与所需连接服务已经部署，客户端到桌面的网络可达。使用 PXVDI 协议时，参阅[安装与配置 PXVDIStream Agent](../../pxvdistream/install.md)。

创建虚拟机后还需加入桌面池并分配用户，或加入共享池并配置池级授权。外部桌面的纳管入口参阅[外部桌面](./external-desktop.md)。
