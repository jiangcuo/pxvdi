# USB 设备库

入口：**主页 → 桌面池 → USB 设备**。

USB 设备库保存可复用的设备匹配规则，供各桌面池的 USB 黑白名单选择。它不是终端实际插入设备的实时清单；空列表表示尚未添加匹配规则。

## 新增设备规则

1. 点击**新增设备**。
2. 填写设备名称、厂商 ID（VID），按需要填写产品 ID（PID）和备注。
3. 核对匹配范围后点击**确认**保存。
4. 在[桌面池 USB 策略](./usb-policy.md)中选择此设备规则。

| 字段 | 要求与匹配范围 |
| --- | --- |
| 设备名称 | 必填，建议注明型号或用途 |
| VID | 必填，4 位十六进制字符，例如 `096E` |
| PID | 可选，填写时为 4 位十六进制字符，例如 `0703` |
| 备注 | 可选，用于记录用途或识别依据 |

VID/PID 不带 `0x` 前缀，需保留前导零。同一组 VID/PID 不能重复添加。PID 留空会匹配整个厂商，而不是单一型号，填写前应明确范围。

可在终端的设备信息或操作系统设备管理工具中查找 VID/PID。UKey、复合设备等建议按实际设备标识建立规则，避免仅依据外观或名称判断类别。

## 搜索、编辑与引用

搜索支持设备名称、VID、PID 和备注。通过行内操作菜单编辑或删除规则，**引用桌面池**列显示使用该规则的池数量。

设备规则由引用它的池共享。修改 VID/PID 后，在后续策略下发时，引用池会使用新的匹配范围；应对相关池重新发起连接并验证。

::: warning 删除会影响引用池
删除设备规则会从所有引用池的 USB 策略中移除该引用。黑名单删除禁止项可能扩大放行范围；白名单删除允许项可能使原有设备无法重定向。操作前检查引用数量及各池的策略模式。
:::

在桌面池向导内点击**新增设备**并保存，也会立即写入全局设备库；之后取消池向导不会撤销已经保存的设备规则。
