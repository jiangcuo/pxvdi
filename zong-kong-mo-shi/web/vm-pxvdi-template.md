# PXVDI 模版管理

PXVDI 模版管理用于查看和维护 PXVDI 模板。

这类模板更适合和快照桌面池配合使用，通常是教学、培训、考试、统一环境交付场景的核心来源。

## 这页和 PVE 模板页有什么区别

- `PVE 模版管理`：更偏普通桌面批量克隆。
- `PXVDI 模版管理`：更偏快照桌面池和统一基线环境。

## 页面

PXVDI 模板页支持：

- 搜索
- 查看状态
- 电源控制
- 打开详情
- 备份
- 克隆
- 转回普通虚拟机
- 批量开关机、批量快照、批量回滚等操作


## 备份模板

对模版进行备份

1. 在模板所在行打开`更多`。
2. 选择`备份`。
3. 选择备份格式、备份存储、备份模式。
4. 填写备注。
5. 提交执行。


## 从 PXVDI 模板克隆桌面的完整步骤

1. 在目标模板所在行选择`克隆`。
2. 选择目标节点。
3. 选择克隆方式。
4. 填写数量、起始编号、命名规则等参数。
5. 提交执行。
6. 回到`桌面管理`或相关桌面池流程中继续交付。


## 转回普通虚拟机

PXVDI 模板页通常支持把模板转回普通虚拟机。

### 适合场景

- 当前模板不再作为模板使用
- 需要把它恢复成可单独运维的普通机器
- 模板维护阶段想先作为普通机处理

### 操作步骤

1. 在目标模板所在行打开`更多`。
2. 选择`转普通虚拟机`。
3. 确认执行。
4. 完成后到`桌面管理`确认结果。

## 使用场景

### 为考试环境发布统一模板

1. 先启动模板虚拟机并做最终配置。
2. 更新必要软件和策略。
3. 为模版打快照，可通过此快照统一发布
