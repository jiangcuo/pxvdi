# 用户模块

入口：**主页 → 用户**。

用户模块集中管理账号、部门和域身份。先准备可用账号，再在桌面池中分配桌面或配置访问授权。

## 功能分工

| 页面 | 用途 |
| --- | --- |
| [用户列表](./user-list.md) | 查询、添加、编辑、导入、同步用户，管理账号状态和密码 |
| [用户注册](./user-register.md) | 审核客户端提交的注册申请 |
| [部门管理](./department.md) | 建立部门层级，调整成员，按部门授权共享桌面池 |
| [域管理](./domain.md) | 配置 AD 连接、测试连接、同步域用户和设置默认域 |
| [域目录](./ad-directory.md) | 浏览实际 AD 组织结构，管理用户、组、组织单位及组成员 |

## 选择账号类型

| 类型 | 身份来源 | 适用场景 |
| --- | --- | --- |
| 平台用户 | PXVDI 平台，所属域为 `pxvdi` | 无 AD 的日常桌面接入 |
| MAC 用户 | 终端 MAC 地址，所属域为 `mac` | 瘦客户端和机房终端接入 |
| AD 用户 | 已配置的 Active Directory 域 | 域账号登录、域组授权和共享会话 |

试用版不显示域管理和域目录，账号类型及导入选项也会随版本调整。

## 身份与授权的关系

建立账号并不自动授予桌面访问权限。普通桌面池需要将用户分配到池内桌面；共享池可以直接授权用户，也可以授权部门或 AD 安全组。账号停用后不能访问已授权资源。

平台**部门**用于组织 PXVDI 用户；AD 的**组织单位（OU）**用于组织域目录对象，两者分别管理。共享池授权部门时包含其下级部门；通过 AD 组授权时使用安全组成员关系。

::: warning AD 操作会同步到域
在用户列表中新增、编辑、启用、停用、重置密码或删除 AD 用户，会调用域服务修改实际 AD 账号。执行前确认对象、域和影响范围。删除域配置与删除 AD 用户的行为不同，参阅[域管理](./domain.md#删除域配置)。
:::
