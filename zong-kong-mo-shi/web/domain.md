# 域管理

入口：**主页 → 用户 → 域管理**。

域管理用于接入 Active Directory，为域用户认证、同步和 AD 组授权提供连接配置。`pxvdi` 和 `mac` 是系统内置域；外部 AD 域需单独添加。

## 添加 AD 域

1. 点击**添加域**。
2. 填写域名、主机地址、端口、管理员 DN 和管理员密码。
3. 点击**连接测试**，确认连接及权限检查结果。
4. 测试通过后点击**确认**保存。

| 字段 | 说明 |
| --- | --- |
| 域名 | AD 域的 DNS 名称，例如 `example.com`；保存后不可更改 |
| 主机地址 | 平台可访问的域控制器地址或主机名 |
| 端口 | 默认 `636`，需与域控制器的 LDAPS 服务一致 |
| SSL | 当前版本强制启用，需准备可用的 LDAPS 服务 |
| 管理员 DN | 绑定账号的完整 DN，例如 `CN=pxvdi-service,OU=Service Accounts,DC=example,DC=com` |
| 管理员密码 | 绑定账号密码；编辑时留空保留原密码 |
| 备注 | 标识用途、环境或维护责任 |

修改主机、端口、DN 或密码后需重新测试连接。测试失败时，依次检查网络可达性、LDAPS 服务、证书配置、DN 和密码。

## 组权限检查

连接成功不代表绑定账号具备读取组授权信息的权限。如测试提示无法读取 `tokenGroups`，应由域管理员检查账号权限，包括适用的 Windows Authorization Access Group 权限。解决后重新测试，再使用 AD 组授权。

域目录中的新增、删除和成员调整还要求相应目录写权限。权限应按实际管理范围配置。

## 同步用户与默认域

使用列表中的**同步用户**更新平台中的该域账号记录。同步后到[用户列表](./user-list.md)检查账号状态和所属域。

**设为默认**用于确定登录时未显式指定域的身份来源。有多个域或重名账号时，建议用户明确选择所属域。

## 删除域配置

删除外部域会移除平台中的该域配置、相关域用户记录及共享池 AD 组授权等关联信息；不会删除 AD 目录中的实际用户或组。系统内置 `pxvdi`、`mac` 域不能删除。

删除前应确认该域不再承担用户登录和桌面池授权。若目标只是删除单个域账号，应在用户列表或域目录核对其具体对象，避免混淆操作范围。
