# 阅卷机房

在这个场景中，用户群体为老师，虚拟机承载的业务是阅卷系统，虚拟机不保存数据，且不常用。

因此我们可以使用`快照桌面池`来部署。
::: tip
使用`普通桌面池`可以通过链接克隆的方式，批量部署虚拟机，但一般中途发现软件有问题，不好批量更新，因为`快照桌面池`更加的合适。
:::


为保证系统的稳定性，虚拟机为2c6G。在一般的64核心的服务器平台中，建议最多使用30个用户。

## 创建虚拟机

根据 `快照桌面池`的部署要求，虚拟机必须存放在`zfs`/`lvm-thin`/`ceph-rbd`中，因为`lvm-thin`是默认安装的类型，我们将虚拟机安装到`local-lvm`中。

假设管理员已经做好了，虚拟机的优化，软件安装，用户创建等操作。

## 将虚拟机转化成PXVDI模版

请先把虚拟机关机，使用下面步骤

`虚拟机管理`-`选中一个虚拟机`-`更多`-`转pxvdi模版`

将虚拟转为pxvdi模板

同时为该创建一个快照。

## 创建桌面池

点击`桌面池`-`桌面池管理`-`添加桌面池`。

- 基本信息
    - 桌面池名称 `随意输入`
    - 桌面池类型 `快照桌面池`
- 网关策略
    - 是否使用网关 `否`
- 资源策略
    - 根据需求开放
- 连接策略
    - 连接类型 `all`
    - spice代理: `任意pxvirt的ip+3128，`
        ::: tip
        例如`10.13.14.1:3128`
        :::
    - RDP连接端口 `默认`
    - 连接参数 `默认`
- 账号策略
    - 系统账号使用规则 `使用账号密码` 
        ::: tip
        `使用账号密码`这个规则，PXVDI会将用户名和密码传递给虚拟机，直接进入到虚拟机桌面。
        :::
保存即可。

## 创建虚拟机

点击`桌面池`的`查看桌面`选项-`添加桌面`

- 选择模板虚拟机 `选择刚才的虚拟机`
- 选择快照 `选择打的快照`
- 克隆数量 `30` 按需选择
- 虚拟机开始编号 `300`
    ::: tip
    `虚拟机开始编号`建议比较偏远的一个号。假设虚拟机开始编号为300。
    那么克隆30个虚拟机，他们的编号就是300-329。如果这中间已有编号，例如已有314，那么第15个虚拟机将会克隆失败。
    :::
- 命名格式 `Exam`
    ::: tip
    设置为`Exam`，那么虚拟机的名称便是，`Exam-1`..`Exam-29`。
    :::

克隆时间可能会有点长，请耐心等待。

如果还需要给这个桌面池扩容，继续执行该功能即可。


## 创建用户

如果阅卷虚拟机 是一个老师专属，那么需要为每个老师创建单独的账号。

如果老师具有阅卷的账号，虚拟机属于公用的，那么可以直接使用`MAC模式`，将瘦客户机注册为账号，适合在机房内使用。

我们这里以`MAC模式`为例。

管理员为瘦客户机配置服务端地址，在设置中开启`mac模式`。点击注册，请输入`友好名称`，例如`sdu01`等。

随后返回服务端，在`用户管理`中进行批量审核用户。


## 分配用户

点击`桌面池`的`查看桌面`选项-`分配用户`


## 更新桌面池

管理员可以对模板虚拟机进行修改，修改之后，再关机，创建一个快照，如`fix2`

随后选择对应桌面池的`查看桌面`-`批量更新`

- `选择模板虚拟机` 固定的选项，无法修改
- `选择快照` 如刚才的快照`fix2`
- `克隆磁盘` 一般只有一个磁盘，选择系统盘。
    ::: tip
    如果虚拟机有数据盘，有系统盘，请选择系统盘。
    :::

    ::: danger
    克隆磁盘是将模板虚拟机的整个磁盘数据应用到虚拟机，而非增量更新。如果虚拟机的数据盘有重要数据，请不要执行此功能。
    :::
