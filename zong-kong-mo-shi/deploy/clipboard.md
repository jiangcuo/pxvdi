# 剪切板控制

## 限制

- Windows 系统

  剪切板控制仅在连接类型为freerdp2下才能够实现

- MacOS 系统
  
  无法复制文件。

- Linux 系统
  
  剪切板控制仅在连接类型为freerdp3下才能够实现

## 使用方法

### Linux和Macos客户端

在桌面池中选择freerdp3，同时开启剪切板控制即可。


### Windows客户端

在桌面池中选择freerdp2，同时开启剪切板控制即可。


## 注意事项

剪切板控制可由网关和操作系统策略覆盖。

参考https://learn.microsoft.com/zh-cn/azure/virtual-desktop/redirection-configure-clipboard?tabs=group-policy
