# 硬件兼容性

PxvdiStream 服务端对硬件的要求取决于是否配置 GPU：

- **配置 GPU**——视频编码由 GPU 承担，CPU 仅负责采集调度与协议处理，配置要求较低；
- **未配置 GPU**——视频编码由 CPU 软件实现，配置要求提高，但无需额外硬件即可运行。

## CPU

支持 x86_64、ARM64、LoongArch 与 RISC-V 四种体系结构，覆盖 Intel、AMD 以及龙芯、鲲鹏、飞腾等国产处理器。

PxvdiStream 已针对各体系结构的 SIMD 指令集完成适配，可有效降低 CPU 占用。

未配置 GPU 时，CPU 的核心数决定可承载的会话数。以 Intel Xeon E5-2490 v4 平台实测为例：单路 1080p@60 会话约占 1 个核心，4 个核心即可支撑一路 4K@30 会话。国产处理器的单核性能与 x86_64 存在差距，实际配置须以目标平台实测为准。

## GPU

GPU 用于提供硬件编码能力。PxvdiStream **不限定显卡型号**，支持 NVIDIA、AMD、Intel 及国产 GPU——只要显卡提供可用的硬件编码器（vaapi）即可。

GPU 的并发能力取决于其配备的编码器数量，而非显存容量。以 NVIDIA P4（1 GB 显存）为例，单实例即可满足 4K@60 的远程会话画质要求。
