# 独立直连

独立直连使用 **PXVDI 桌面客户端的本地连接模式**，直接访问安装了 PXVDIStream Agent 的虚拟机或物理机，无需先登录云桌面平台。主机地址、协议和账号保存在本地连接卡片中，后续点击卡片即可连接。

本文说明 PXVDIStream 的直连流程。截图采自 macOS 版桌面客户端，Windows、Linux 客户端的可用选项以实际版本为准。

## 连接前准备

1. 在目标主机按[安装与配置 Agent](./install.md)完成服务部署，确认服务正在运行。
2. 准备目标主机的 IP 地址或域名及相应连接凭据；账号选择见下文。
3. 确认客户端能够直接访问目标主机。PXVDI 本地连接使用默认服务端口 **9923**。
4. 在客户端**设置 → 常规**中关闭**外网模式**，点击**保存配置**。

本地连接的地址填写在远程桌面记录中；**设置 → 服务器**中的地址用于云桌面平台登录。帧率、码率等默认选项在**常规 → 视频配置**中调整，完整设置说明见[客户端使用说明](../client/Usage.md)。

## 进入本地连接

启动 PXVDI 桌面客户端，在首页右上角点击**本地连接**，进入自行添加的远程桌面列表。右上角的**云桌面**可以切回平台登录首页。

## 添加 PXVDI 桌面

点击左上角**添加**，在“添加远程桌面”弹窗中填写连接信息，然后点击**保存**。

| 字段 | 填写说明 |
| --- | --- |
| 连接类型 | 选择 **PXVDI**，通过 PXVDIStream 连接目标主机 |
| 备注 | 可选，用于识别桌面；未填写时以主机地址作为卡片标题 |
| IP或域名 | 填写目标主机地址，例如 `192.0.2.20`；使用默认端口 9923，无需添加 `http://` 或 `https://` |
| 用户名、密码 | 填写目标服务或系统会话的连接凭据，按下文的认证模式选择 |

### 连接账号如何选择

本地连接使用卡片中保存的账号和密码，账号应与目标主机启用的认证模式一致。未启用 `rdsh`、使用配置账号认证时，填写 Agent 配置文件中 `username`、`password` 对应的服务连接凭据；独立系统会话使用目标操作系统账号。平台账号只有在目标认证环境能够识别该账号时才能使用。

### Linux XRDP 会话直连

按[Linux 安装](./install.md#linux-安装)准备 XRDP 与 xorgxrdp，并在 Agent 中启用 `rdsh=true`。本地连接卡片仍选择 **PXVDI**，用户名和密码填写**目标 Linux 系统账号及密码**。

连接时，本机 XRDP 完成系统认证并创建或恢复该用户的 X11 桌面，PXVDIStream 负责画面、输入和串流。此模式不使用配置文件中的服务账号，也不需要将连接类型改为 RDP。会话隔离与恢复说明见[会话模式](./Sessions.md)。

## 连接与会话操作

保存记录后，点击桌面卡片主体建立连接。已有记录可通过卡片底部的**编辑**修改；**删除**仅移除本地连接记录，不会删除远端桌面。

使用内嵌客户端时，在**设置 → PXVDI**中关闭**使用外部 SDL 客户端**并保存，再建立连接。远程桌面在独立会话窗口中打开，顶部悬浮工具栏提供全屏、功能菜单、发送按键和断开操作。

## 常见问题

| 现象 | 检查内容 |
| --- | --- |
| 点击卡片后无法连接 | IP或域名是否正确、客户端到目标主机的网络、默认端口 9923、Agent 服务状态，以及外网模式是否关闭 |
| 提示认证失败 | 卡片账号是否与服务认证或系统会话模式匹配；Linux XRDP 模式检查系统密码、PAM 和 XRDP 策略 |
| Linux 认证成功但没有画面 | 按[Linux 安装](./install.md#linux-安装)检查 xorgxrdp、桌面启动环境、用户主目录和会话日志 |
| 需要调整帧率、码率或显示效果 | 修改客户端默认设置，或使用内嵌会话的功能菜单；具体选项见[客户端使用说明](../client/Usage.md) |
