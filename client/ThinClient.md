# 瘦客户端使用说明

PXVDI 客户端有2种，一种是桌面客户端，一种是瘦客户端，瘦客户端为嵌入式或者低配置机器设计！占用系统资源小，功能简单高效，并且被我们的瘦客户端系统集成。

注意：这里是我们的瘦客户端软件的说明，不是首客户端系统说明，系统说明参考[瘦客户端系统说明](./ThinOS.md)

## 瘦客户端支持的系统和架构

Linux: arm64/amd64/riscv64/loongarch64

## 瘦客户端软件下载

瘦客户端仅提供基于debian13的deb包，集成到瘦客户端系统中，如果需要单独下载，可前往[镜像目录](https://mirrors.lierfang.com/pxcloud/pxvdi/dists/trixie/main/)下载。

## 瘦客户端配置

主程序路径: `/opt/com.lierfang.pxvdi/pxvdi-thin-client`
配置文件路径: `~/.lierfang/pxvdiconfig.json`

## 瘦客户端OEM配置

瘦客户端可以自定义logo和footer名称

请自己上传logo到瘦客户端系统当中。

比如你的logo为 `mylogo.png`，请上传到 `/usr/share/` 目录下，然后在配置文件中设置

```json
{
    "logo_path":"/usr/share/mylogo.png"
}
```

footer名称可以在配置文件中设置
```json
{
    "footer":"你的footer名称"
}
```

这样配置后，瘦客户端启动时会显示你自定义的logo和footer名称。


## 瘦客户端设置菜单

### 常规设置
- 连接类型: 默认的连接类型。设置为默认后，点击桌面卡片就可以连接虚拟机
- 串口: 这个没用，即将废弃。
- 调试模式: 开启后，会在终端输出调试信息。
- 显示菜单栏: 开启后，会显示freerdp的菜单栏，可以控制usb设备、全屏等
- 全屏模式: 全屏启动
- 多屏模式: 当开启全屏模式的时候，可以开启多屏，此时freerdp会使用多屏模式
- 自动登录: 开启后，会自动登录到pxvdi服务器，并且如果只有一个虚拟机，将会自动连接
- 外网模式: 开启后，会做一些外网的优化，例如使用桌面池的网关，使用内置的spice服务器。
- Mac模式: 以网卡mac为用户名的登录方式。开启mac模式之后，可以注册为mac用户，在服务器的机房模式下远程管理。

### 连接设置 - RDP
这里的选项会覆盖桌面池设置中的连接选项。本地覆盖远程下发的配置。

- 解码器: 设置解码器，如果cpu性能不强，使用软件解码器RFX，如果cpu性能强，可以使用硬件解码器AVC444。
- 色深: 设置色深，通常设置为24位。
- 声音: 是否开启声音
- 麦克风: 是否开启麦克风
- 缩放: 设置远程缩放
- 网络类型: 不同的网络类型有不同的优化
- Admin会话: 连接到管理员会话
- 显示菜单栏: 开启后，会显示freerdp的菜单栏，可以控制usb设备、全屏等

### 连接设置 - PXVDI

- 解码器: 支持软件、h265\h264硬解码，如果瘦客户端在硬件解码器下有问题，请使用软件解码器
- 渲染器: SDL-> CPU渲染，OpenGL-> GPU渲染。推荐GL，延迟低。
- 比特率: 设置比特率，越高画质越好
- 帧率: 设置帧率，越高越流畅，瘦客户端性能不行，可以设置为30

### 连接设置 - Moonlight

- 解码器: 支持软件、h265\h264硬解码，如果瘦客户端在硬件解码器下有问题，请使用软件解码器
- 帧率: 设置帧率，越高越流畅，瘦客户端性能不行，可以设置为30
- 编码器: 远程服务端的编码器，通常设置为H264
- 游戏优化: 启动moonlight的优化模式，可以提高游戏体验
- 444色深: 启用444色深，可以提高颜色精度，但是会降低性能
