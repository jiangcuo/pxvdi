# PXVDI 桌面客户端使用说明

本文介绍 PXVDI 桌面客户端的首次连接、设置及日常操作，适用于 Windows、macOS 和 Linux。界面截图采自 macOS 版 4.1.2；部分选项会根据操作系统、客户端组件和服务器配置显示。

## 1. 安装

前往[梨儿方官网](https://www.lierfang.com)下载与操作系统及处理器架构对应的客户端，并完成安装。使用其他连接协议时，请按部署要求准备对应组件。

## 2. 使用说明

### 2.1 首次连接云桌面

1. 启动客户端，在首页右上角点击齿轮图标，打开**设置**。
2. 选择左侧的**服务器**，输入管理员提供的完整服务器地址，例如 `https://gw.pxvdi.lierfang.com:16003`。地址应包含 `http://` 或 `https://`；使用非默认端口时，还需填写端口号。
3. 点击**测试服务器**，确认地址是否可用。测试使用输入框中的地址，测试成功后仍需点击**保存配置**。
4. 如需切换界面语言，进入**常规 → 语言设置**，选择所需语言。
5. 关闭设置弹窗，输入云桌面账户和密码，点击**登录**。
6. 登录成功后，点击分配给您的桌面卡片，开始连接。

**保存密码**用于记住登录凭据；**自动登录**用于在下次启动客户端进入云桌面时尝试自动登录。自动登录需要有效的账户信息。没有账户时，可点击**立即注册**，是否允许注册由服务器决定；扫码登录也需要服务器支持。

### 2.2 设置的基本操作

新版设置采用统一的侧栏分区弹窗。原来的“高级设置”已合并到**常规、RDP、PXVDI、Moonlight**等分区中，直接点击左侧菜单即可查看。

| 分区 | 主要用途 |
| --- | --- |
| 服务器 | 配置云桌面服务器地址、证书选项，测试服务器连接 |
| 常规 | 设置语言、默认连接类型、自动登录、外网模式、视频及显示选项 |
| RDP | 设置 RDP 的画面、声音、麦克风、桌面缩放及网络参数 |
| PXVDI | 设置 PXVDI 传输协议、桌面缩放及 SDL 客户端选项 |
| Moonlight | 设置 Moonlight 编解码、游戏优化及画面选项 |
| 关于 | 查看版本及联系信息、导出日志，使用平台专用功能 |
| 隐私 | 查看隐私政策 |
| 许可 | 查看第三方组件及开源许可 |

修改设置时，请注意以下操作规则：

- **保存配置**：一次保存各分区中已修改的设置，无需在每个分区分别保存。协议参数通常在下一次建立连接时使用。
- **重置**：重新读取已保存的配置，撤销当前尚未保存的修改。此按钮不会恢复出厂默认值。
- **关闭**：点击右上角的 × 或弹窗外部关闭设置；关闭不会自动保存普通设置。
- **即时操作**：语言选择立即保存并切换界面；开启全屏模式时，窗口会立即进入全屏。这些操作不应视为尚未生效的普通修改。
- **滚动查看**：常规、RDP、PXVDI 等分区可能包含超出窗口高度的内容，请在右侧内容区域向下滚动；底部操作按钮始终可见。

| 设置项 | 可选值及用途 |
| --- | --- |
| 解码器 | 自动、AVC420（H.264）、AVC444（H.264）、RFX。需要远端及客户端支持所选模式，通常先保持自动 |
| 色深 | 自动、32、24、16、15 位。较高色深可提供更丰富的颜色 |
| 声音 | 自动、开启、关闭；控制远端声音在本地播放 |
| 麦克风 | 自动、开启、关闭；控制本地麦克风向远端重定向 |
| 桌面缩放 | 自动、100%、125%、150%、175%、200%；调整远端桌面中文字和控件的缩放比例 |
| 网络类型 | 自动、Modem、Broadband（low）、Broadband（high）、WAN、LAN；为 RDP 提供相应网络场景参数 |
| Admin 会话 | 请求以管理会话方式连接。仍需远端支持及相应账户权限，此开关不会授予管理员权限 |

| 设置项 | 说明 |
| --- | --- |
| PXVDI传输协议 | 可选 WebSocket 或 WebRTC，需与服务器能力及网络环境匹配 |
| 桌面缩放 | 使用内嵌 PXVDI 客户端时显示。可选“跟随本地显示缩放”或 100%、125%、150%、175%、200%，用于设置远端 DPI；与 RDP 的桌面缩放独立 |
| 使用中继 | 在“常规 → 外网模式”开启后显示。开启后强制使用 TURN 服务器中继连接；关闭后自动选择连接路径。需服务器提供相应能力 |
| 使用外部 SDL 客户端 | 开启后使用独立的 Pxvdistream SDL 客户端；关闭后，PXVDI 会话在应用内的独立窗口中打开 |
| 解码器 | 外部 SDL 客户端选项：`auto`、`software`、H.264、H.265。一般先使用自动，遇到兼容性问题时再调整 |
| 渲染器 | 外部 SDL 客户端选项：`auto`、OpenGL、SDL Canvas、Sink。一般保留自动；如需调整，按终端图形环境选择 |
| USB 自动重定向 | 建立会话时自动尝试重定向允许连接的 USB 设备，仍受服务器策略、设备支持及本机权限约束 |

**码率和帧率统一在“常规 → 视频配置”中设置。** SDL 解码器及渲染器不会配置应用内的客户端；外部 SDL 客户端也不读取此处内嵌客户端的桌面缩放选项。开启自动重定向并不表示所有 USB 设备都可重定向。

**关于**显示应用名称、版本号、开发商和联系邮箱，并提供以下操作：

**隐私**和**许可**分别位于左侧独立分区。许可分区列出第三方组件名称、版本及许可证，可进一步查看完整许可文本。

首页右上角的**本地连接**用于切换到自行添加的远程桌面列表，无需先登录云桌面账户；切换后，可通过**云桌面**返回云桌面首页。

### 2.5 PXVDI 内嵌客户端会话

在**设置 → PXVDI**中关闭**使用外部 SDL 客户端**，点击**保存配置**后，再通过云桌面卡片或本地连接卡片建立 PXVDI 连接，即可使用内嵌客户端。远程桌面在应用的独立会话窗口中打开，顶部悬浮工具栏提供会话控制。

#### 2.5.1 顶部悬浮工具栏（状态栏）

工具栏收起时，点击顶部的**三点手柄**即可展开。未固定时，工具栏会在空闲后自动收起；需要持续显示时，可点击图钉固定。拖动右侧的**六点手柄**可调整工具栏的水平位置。

| 操作入口 | 用途 |
| --- | --- |
| 图钉 | 固定或取消固定工具栏，控制是否自动收起 |
| 全屏图标 | 进入或退出当前会话窗口的全屏模式 |
| 功能 | 打开 USB 重定向、文件管理、相对鼠标及显示参数菜单 |
| 发送按键 | 向远端发送 `Ctrl + Alt + Del` 或 `Alt + F4`；后者可关闭远端当前活动窗口 |
| 隐藏 | 完全隐藏工具栏及三点手柄，远程连接继续运行；按 `Ctrl + Alt + Shift + S` 再次显示 |
| 红色 × | 直接断开当前会话。请先保存远端工作；此操作不会向虚拟机发送关机指令 |
| 六点手柄 | 拖动工具栏，避免遮挡远端操作区域 |

| 功能 | 说明 |
| --- | --- |
| USB 重定向 | 打开 USB 设备重定向界面，将支持的本地设备连接到远端。需要客户端原生组件、服务器策略及本机权限支持 |
| 文件管理 | 打开会话文件管理界面；启用文件传输服务时显示此入口 |
| 相对鼠标 | 切换鼠标相对移动模式，适用于游戏、三维视角等场景。需要本机支持，且会话允许输入；窗口失去焦点或连接结束时会释放鼠标捕获 |
| 分辨率 | 提供自动适应、高清显示及远端支持的分辨率列表。手动选择分辨率后停止随窗口自动调整；可重新启用自动适应 |
| 桌面缩放 | 调整远端文字和控件的 DPI 缩放。可跟随本地显示缩放，或选择 100%、125%、150%、175%、200%、250%、300%；远端支持独立 DPI 调整时显示 |
| 帧率 | 请求远端使用 30、60、90、120、144、165 或 240 FPS；远端支持动态帧率调整时显示，实际帧率受远端性能、解码能力及网络影响 |
| 码率 | 调整当前会话的视频目标码率，预设为 5、10、30、50、100 Mbps；菜单还可能显示远端已确认的当前码率 |

**分辨率、高清显示和桌面缩放分别控制不同的显示效果：**分辨率决定远端画面的像素尺寸；高清显示（HiDPI）使自动适应时的画面像素考虑本地显示密度；桌面缩放决定远端文字和控件的大小。修改桌面缩放不会同时修改分辨率或帧率。切换高清显示会重新启用自动适应。

打开分辨率菜单时，客户端会请求远端支持的模式；列表尚未返回或远端没有可选模式时，会显示相应提示。分辨率、帧率和码率的调整需要远端处理并确认，最终效果以远端返回的状态和实际画面为准。

工具栏中的**帧率、码率调整仅作用于当前连接**。如需设置后续连接的默认值，请修改**设置 → 常规 → 视频配置**并保存。

#### 2.5.3 会话快捷键

在会话窗口获得键盘焦点时，可使用以下快捷键；macOS 上的 `Alt` 对应 `Option` 键。

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Alt + Shift + S` | 显示或隐藏本地会话工具栏 |
| `Ctrl + Alt + Shift + M` | 切换相对鼠标模式，需要本机支持且会话允许输入 |
| `Ctrl + Alt + Shift + Q` | 直接断开当前会话，与工具栏红色 × 的行为相同 |

需要向远端发送系统组合键时，建议使用**发送按键**菜单。上述三组快捷键由本地客户端处理。

## 3. Pxvdi-thin-client 嵌入式瘦客户端

Pxvdi-thin-client 面向资源受限的嵌入式终端，在 4.x 版本瘦客户端系统中作为默认客户端。部署和配置请参阅[瘦客户端说明](./ThinClient.md)。

## 4. Pxvdistream SDL 客户端使用

Pxvdistream 是独立的 PXVDI SDL 客户端，支持硬件解码。可在**设置 → PXVDI → 使用外部 SDL 客户端**中启用，实际解码能力与性能取决于终端硬件和驱动。

单独下载请前往 [Pxvdistream 下载目录](https://mirrors.lierfang.com/pxcloud/pxvdi/PxvdiStream/)。

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Alt + Shift + Q` | 强制关闭客户端 |
| `Ctrl + Alt + Shift + S` | 显示或隐藏悬浮菜单 |
| `Ctrl + Alt + Shift + M` | 切换相对鼠标模式，适用于 FPS 等需要持续捕获鼠标的场景 |

### 悬浮菜单

悬浮菜单提供 USB 重定向、文件管理和安全键盘等功能，具体可用项取决于会话及服务器配置。

安全键盘用于部分 UKey 重定向后需要物理按键事件的输入场景。它以物理按键事件方式向远端发送输入，能否使用仍取决于 UKey 及其软件要求。

## 5. Windows RDP 客户端使用

使用 `Ctrl + Alt + Shift + S` 显示或隐藏悬浮菜单，其余操作可按工具栏上的功能名称使用。RDP 的画面、音频及缩放偏好请在**设置 → RDP**中配置。
